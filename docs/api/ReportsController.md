# **FinTrack API: Reporting Service (Reports Controller)**

This document describes the `ReportsController` endpoint, which allows users to analyze their financial data (transactions, accounts, budgets) and convert it into professional reports in various formats.

*Controller Base Path:* `/Reports`

---

## General Information

### Authentication

**All endpoints** in this controller require authorization. Requests must include a valid JWT `Bearer Token` in the `Authorization` header.

### Role in the Architecture: Data Collection and Document Generation

The `ReportsController` acts as an orchestrator:

1.  **Single Entry Point:** All reporting requests are received through a single endpoint, `/generate`.
2.  **Dynamic Data Collection:** Based on the `reportType` field in the request (`Transaction`, `Account`, `Budget`), a specific method is called to gather the relevant data from the database. These methods dynamically build the database query using other filters from the request (date range, account IDs, etc.).
3.  **Delegation to Document Service:** The collected and formatted data (as an `IReportModel`) is sent to the `IDocumentGenerationService`, along with the `exportFormat` (`PDF`, `Excel`, etc.) specified in the request.
4.  **File Response:** The report generated by the document service (e.g., a PDF or Excel file) is returned directly to the user as a downloadable `File` response.

### `ReportType` and `ExportFormat` Values

*   **`reportType`:** Specifies the type of report to be generated.
    *   `Transaction`
    *   `Account`
    *   `Budget`
*   **`exportFormat`:** Specifies the output format of the report.
    *   `PDF`
    *   `Word`
    *   `Excel`
    *   `XML`
    *   `Text`
    *   `Markdown`

---

## Endpoints

### 1. Generate a Dynamic Report

Creates a financial report based on user-defined criteria and returns the file in the specified format.

*   **Endpoint:** `POST /Reports/generate`
*   **Description:** This multi-purpose endpoint can generate different reports based on the data in the submitted `ReportRequestDto`.
*   **Authorization:** Required (`User` or `Admin` role).

#### Request Body (`ReportRequestDto`)

This DTO uses different fields depending on the requested report type.

| Field | Type | Description | Applicable Report Types |
| :--- | :--- | :--- | :--- |
| `reportType`| `string`| The type of report to be generated. | **All (Required)** |
| `exportFormat`| `string`| The output format of the file. | **All (Required)** |
| `startDate` | `string`| The start date for the report (ISO 8601). | `Transaction`, `Budget` |
| `endDate` | `string` | The end date for the report (ISO 8601). | `Transaction`, `Budget` |
| `date` | `string` | To retrieve transactions for a single day only (ISO 8601).| `Transaction` |
| `selectedAccountIds`|`integer[]`| Includes data only for the specified account IDs.| `Transaction`, `Account` |
| `selectedCategoryIds`|`integer[]`| Includes data only for the specified category IDs.| `Transaction`, `Budget` |
| `selectedBudgetIds`|`integer[]`| Includes data only for the specified budget IDs.| `Budget` |
| `isIncomeSelected`|`boolean` | Include income transactions (`true`/`false`).| `Transaction` |
| `isExpenseSelected`|`boolean` | Include expense transactions (`true`/`false`).| `Transaction` |
| `minBalance`| `number` | Minimum account balance filter. | `Account` |
| `maxBalance` | `number` | Maximum account balance filter. | `Account` |

#### Request Body Example (Transaction Report)
```json
{
  "reportType": "Transaction",
  "exportFormat": "PDF",
  "startDate": "2024-05-01T00:00:00Z",
  "endDate": "2024-05-31T23:59:59Z",
  "selectedAccountIds": [1, 3],
  "isExpenseSelected": true,
  "isIncomeSelected": false
}
```

#### Success Response
*   **Status Code:** `200 OK`
*   **Content-Type:** The appropriate MIME type for the requested format (e.g., `application/pdf`, `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`).
*   **Content:** The generated report file itself (binary data).

#### Error Responses
*   `400 Bad Request`: If the `reportType` or `exportFormat` is unsupported, or if the request is invalid.
*   `404 Not Found`: If no data is found matching the specified criteria.
*   `500 Internal Server Error`: If an unexpected error occurs during report generation.
