# **FinTrack API: FinBot Chat Service (Chat Controller)**

This document describes the `ChatController` endpoint, which enables users to communicate with FinTrack's AI-powered assistant, **FinBot**.

*Controller Base Path:* `/Chat`

---

## General Information

### Authentication

Endpoints in this controller **require authorization**. Requests must include a valid JWT `Bearer Token` in the `Authorization` header.

**Header Example:**
`Authorization: Bearer <YOUR_JWT_TOKEN>`

### Role in the Architecture: Proxy and Security Layer

The `ChatController` acts as a **Proxy**. It prevents direct access to the artificial intelligence service (the Python FinBotWebApi) and establishes a security layer. The workflow is as follows:

1.  **Client (WPF/Mobile) -> ChatController:** The user sends their message to this controller.
2.  **Authentication:** The `ChatController` validates the incoming `Bearer Token` and identifies the user via their `userId`.
3.  **Request Enrichment:** It enriches the incoming request with important information, such as the user's `userId` and the original `authToken`.
4.  **ChatController -> FinBotWebApi (Python):** It forwards the enriched and secured request to the Python-based AI service running in the background.
5.  **Response Flow:** It receives the response from the Python service and forwards it directly back to the client.

This architecture ensures that the AI service only processes requests that are trusted and authenticated.

---

## Endpoints

### 1. Send a Message to FinBot

Allows the user to start or continue a conversation with FinBot.

*   **Endpoint:** `POST /Chat/send`
*   **Description:** Receives the user's message and session information, forwards it to the FinBot service in Python, and returns the response from it.
*   **Authorization:** Required (`User` or `Admin` role).

#### Request Body (`ChatRequestDto`)
| Field | Type | Description | Required? |
| :--- | :--- | :--- | :--- |
| `clientChatSessionId`| `string` | A unique ID generated by the client to track the conversation session. | Yes |
| `message` | `string` | The text message sent by the user to FinBot. | Yes |

#### Request Body Example
```json
{
  "clientChatSessionId": "a1b2c3d4-e5f6-7890-1234-567890abcdef",
  "message": "How much have I spent on groceries this month?"
}
```

#### Success Response
*   **Status Code:** `200 OK`
*   **Content:** A `ChatResponseDto` object. This response comes directly from the Python service.
    ```json
    {
      "sessionId": "a1b2c3d4-e5f6-7890-1234-567890abcdef",
      "reply": "Your grocery expenses this month total 2,350.50 TRY. This is a 15% increase compared to last month. If you would like a detailed breakdown, you can say 'List my grocery expenses'.",
      "timestampUtc": "2024-05-24T14:30:00Z"
    }
    ```

#### Error Responses
*   **Status Code:** `401 Unauthorized`
    *   When a valid token is not provided.
*   **Status Code:** `500 Internal Server Error`
    *   If the `.NET` service cannot connect to the Python service: `{"error": "Failed to contact the ChatBot service."}`
    *   If the Python service URL is missing from `appsettings.json`: `{"error": "ChatBot service configuration error."}`
*   **Status Code:** `502 Bad Gateway` or other `5xx` errors returned from the Python service.
